# Fg小助手（ArcDesk）

#### 介绍

基于 Wails v2（Go + React）的一体化安全测试辅助桌面工具，同时内置 AI Coding Agent 工作台。集成渗透测试、信息收集、资产测绘、漏洞库与 PoC 管理、端口/内网扫描、WebShell 检测（文件扫描 + 流量还原）、PCAP 深度分析、数据库助手、应急响应取证、C2 管理、情报舆情监控、AK 管理、接码平台、HTTP 数据重放等 40+ 实战模块，多数据源可视化聚合，自动化重复性安全测试工作。

- **开箱即用**：单安装包分发，无需配置运行环境，Windows 10/11 直接运行
- **本地优先**：扫描引擎、漏洞库、指纹库全部本地运行，API Key 加密存储于本机
- **离线激活**：内置激活向导，支持离线签发与校验
- **AI 加持**：AI Agent 支持 Diff 审批、经验库沉淀、MCP/Skills 扩展、沙盒预览与 normal/plan/yolo 三档权限模式

#### 软件架构

**技术栈**：Go 1.25（Wails v2 桌面框架）+ React 18 + TypeScript + Vite，前端由系统 WebView2 渲染，无浏览器依赖。

```
├── desktop/                    # Wails 应用壳（app.go + 各模块 *_app.go 绑定层）
│   ├── frontend/               # React 18 + TS 前端（安全组件二级懒加载，首屏轻量）
│   │   └── components/security/  # 60+ 安全功能组件
│   ├── emergency_collectors/   # 应急响应采集器
│   └── robot/                  # IM 机器人网关（8 平台）
├── internal/                   # Go 核心内核（Agent、扫描引擎、协议解析等）
├── data/                       # 离线数据（漏洞库、指纹规则、内置字典）
└── cmd/                        # 独立辅助工具
```

#### 安装教程

1. 前置要求：Windows 10/11 x64，系统自带 WebView2 Runtime（如缺失安装器会自动提示安装）
2. 从 Releases 下载最新安装包（NSIS 安装器），双击运行，按向导完成安装
3. 首次启动进入激活向导，按提示完成激活（支持离线激活码）
4. 在「设置 → 平台配置」中按需填写各数据源 API Key，保存即生效

#### 使用说明

1. 启动后通过左侧模块导航切换功能域（渗透测试 / 信息收集 / 资产测绘 / 应急响应 / 情报舆情 / 工具箱等）
2. AI 工作台选择会话模式：`normal`（逐步审批）/ `plan`（先规划后执行）/ `yolo`（自动执行，谨慎使用）
3. 扫描类任务提交后可在进度面板实时查看结果，支持一键导出报告（docx/CSV）
4. IM 机器人在「设置 → 机器人」中绑定平台 Token 后即可远程接收任务推送与告警
